# Code of Conduct

We are committed to a welcoming, harassment-free project for everyone.

Be respectful, assume good intent, give actionable technical feedback, and avoid personal attacks, discriminatory language, sexualized content, or publishing another person's private information. Maintainers may edit, remove, or reject participation that violates these expectations.

Report conduct concerns privately through the repository owner's GitHub profile contact method. Maintainers will review reports fairly and protect reporters' privacy where possible.
