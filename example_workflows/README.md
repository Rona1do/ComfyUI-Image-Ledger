# Example workflow

`Image Ledger - Wan 2.2 5B I2V.json` is an image-to-video template for ComfyUI's native Wan 2.2 nodes. Install the [Wan 2.2 5B models](https://docs.comfy.org/tutorials/video/wan/wan2_2), then put source images under `ComfyUI/input/AI/<category>/`. Open **Global Image Ledger**, choose the category, pick an image, and click **Run this**. The panel replaces the workflow's **First Frame** image and queues it. A successful saved video marks that source complete.

The workflow's `example.png` is a placeholder; pick a source through the Image Ledger panel before queueing. Moving completed sources is off by default.
